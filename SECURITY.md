# Security policy

## Supported versions

Flutterware is currently a prototype. Security fixes are applied to the latest
commit on `main`; no released version is yet supported for production use.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting feature on this repository. Include affected
versions, reproduction steps, impact, and any suggested mitigation.

Never submit real signing keys, access tokens, private device logs, or other
secrets as part of a report. Maintainers will acknowledge a report when it has
been reviewed and will coordinate disclosure after a fix is available.
